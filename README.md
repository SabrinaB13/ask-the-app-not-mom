\# Ask the App, Not Mom



Ask the App, Not Mom is a family-focused grocery and meal planning web application designed to make weekly meal planning easier. The app helps users manage grocery lists, plan meals, and eventually use AI to turn plain-language requests into meal ideas and organized shopping lists.



\## Planned Features



\- Add, edit, and delete grocery items

\- Check off grocery items while shopping

\- Organize groceries by category

\- Create a weekly meal plan

\- Save favorite family meals

\- Generate grocery lists from meal plans

\- Use AI to create meal ideas and grocery lists from simple requests



\## Tech Stack



\- React

\- Node.js

\- Express

\- MongoDB

\- GitHub Actions

\- LLM API integration



\## Project Status



This project is currently in the planning and setup stage.
